# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give and accept constructive feedback, and focus on what is best for
the community. Harassment of any kind is not tolerated.

Instances of unacceptable behavior may be reported privately to the maintainer through
[GitHub Security Advisories](https://github.com/burhan-mujahid/repo2video/security/advisories/new) or by contacting
the maintainer via their GitHub profile. All reports will be reviewed promptly and handled confidentially.
