First public release of repo2video: turn any code repository into a narrated, scored film.

## Highlights

- **Five show formats from one command.** `marketing` renders a trailer, `engineering` a metro ride through the code, `onboarding` a video-game quest, `release` a breaking-news broadcast and `social` a 9:16 short.
- **Facts, not filler.** Every line of narration comes from the repository: the README, manifests, the CHANGELOG, git history, and code shown verbatim with its path and line range.
- **A voice that reads code.** Names are read with their symbols (`brief.md` is "brief dot M D"), heteronyms are resolved by context ("goes live" and "we live"), and versions and units are read naturally.
- **An original score.** Five procedurally synthesized scores and nineteen sound effects, beat-quantized cuts, cue-driven effects and a -14 LUFS master.
- **Frame-exact rendering.** A deterministic scene engine with identical output in the built-in renderer, HyperFrames and Remotion.

## Install

```sh
pip install git+https://github.com/burhan-mujahid/repo2video@v0.1.0
repo2video rtk-ai/rtk -m all
```

## Samples

The attached videos were rendered without manual edits: five formats from [rtk-ai/rtk](https://github.com/rtk-ai/rtk), onboarding from [tj/commander.js](https://github.com/tj/commander.js), and a trailer from [karpathy/autoresearch](https://github.com/karpathy/autoresearch). Watch them with sound on, or on the [website](https://burhan-mujahid.github.io/repo2video/#formats).
