Formats

One repository. Five different films.

Each mode is a complete show with its own script, visual language, voice, score and caption style. All five samples below were rendered from the same repository with a single command.

    Pipeline

    From source tree to final cut.

    Six stages, each with one job. Facts flow in one direction, and the story file in the middle is the contract every renderer reads.

    01

    Analyze

    analyze.py

    Reads the README, manifests, lockfiles, CHANGELOG and git history. Finds the entry point, traces real function calls and builds the import graph.

    02

    Plan

    plan.py

    Turns facts into a show: scenes, narration and on-screen text, each line traceable to a file, line range or commit range.

    03

    Speak

    speech.py

    Normalizes names, numbers and units, resolves heteronyms by context, and synthesizes Kokoro speech with per-word timings.

    04

    Lay out

    engine.js

    Quantizes scene cuts to the beat, aligns the drop to a bar, and emits a sound cue for every visible action.

    05

    Score

    sound.py

    Synthesizes the score and effects from oscillators and filters, ducks the music under the voice and normalizes loudness.

    06

    Render

    render.py

    Seeks a headless browser frame by frame and encodes H.264 with AAC, plus a README-sized GIF.

    Facts, not filler

    Every claim in a video comes from the repository. Code on screen is copied verbatim with its path and line range. Numbers come from the README or from git. When text has to be shortened it is shown on screen, but the narrator only reads complete clauses.

    The story file is plain JSON. Edit any line and render again; the picture, captions and sound follow the new timing automatically.

    // story.json (abridged)
{
  "mode": "engineering", "format": "metro",
  "music": "synthwave", "bpm": 100, "voice": "am_michael",
  "scenes": [
    { "type": "stop", "symbol": "entry",
      "path": "src/lib.rs", "start": 2317, "end": 2330,
      "highlight": [10],
      "evidence": "src/lib.rs:2317-2330",
      "narration": "Next stop: `entry()`, in `src/lib.rs`." }
  ]
}
    Voice

    A narrator that reads code correctly.

    Text-to-speech engines mispronounce code. repo2video puts three layers in front of the voice so file names, versions and ambiguous words come out the way an engineer would say them.

    01

    Names are read with their symbols

    Paths, files, identifiers, flags and package names are detected and verbalized. Punctuation in ordinary prose stays silent.

    02

    Heteronyms follow the sentence

    Part-of-speech tags from spaCy drive misaki's pronunciation dictionary, and rule overrides fix what taggers miss, such as "ship it live" and "have you read".

    03

    Numbers, units and jargon

    Versions, ranges, units and approximations become words, and a technical lexicon covers terms like config, README, JSON and nginx.

    Sound

    An original score for every format.

    No samples and no stock music. Every note and effect is synthesized from oscillators, envelopes and filters in NumPy, so each video ships with music that is entirely its own and free of licensing questions.

    Trailer92 BPM

    Braams, taiko toms and a riser into an impact on the title reveal, then a driving pulse.

    Synthwave100 BPM

    Octave bass, arpeggiated saws and a gated snare for the ride through the code.

    Chiptune132 BPM

    Square-wave lead, triangle bass and noise drums, with coins and level-ups on cue.

    News116 BPM

    Ticking hats, timpani and brass stabs under a sting on the breaking banner.

    Trap145 BPM

    808 glides, hi-hat rolls and plucks in half time for the vertical short.

    On the beatScene durations are quantized to beats; the drop lands on a bar line.
    On cueWhooshes, typing, coins and impacts are triggered by what is on screen.
    -16 dBVoice normalized while speaking; the music is ducked about 14 dB beneath it.
    -14 LUFSIntegrated loudness of the final mix, the common streaming target.
    Engine

    Every frame is a function of time.

    The scene engine is a single dependency-free script. Nothing on screen depends on the previous frame, a clock or randomness without a seed, so any host can seek it to any moment and get the same picture.

    Composable motion

    An animation registry where an element can rise, bob and punch at once. Transforms are composed per frame rather than overwritten.

    29 animation kinds

    Camera and transitions

    Slow push-ins, beat punches after the drop, and a transition language per format: flash cuts, train slides, iris wipes, news swooshes, punch zooms.

    5 transition styles

    Seeded particles

    Sparks, confetti, pixels and icon bursts are replayed from their seed on every frame, which makes them seekable and identical across renderers.

    deterministic

    A mascot that talks

    Bit appears in five costumes, blinks, waves and cheers, and moves its mouth only while a word is being spoken, using the voice's word timings.

    lip-synced

    Captions per show

    Letterbox subtitles, an amber LED station board, an RPG dialog box that types as it speaks, closed captions and large word-by-word captions.

    5 caption styles

    Portable by design

    Bundled fonts and an original SVG icon set mean renders do not depend on the fonts or emoji installed on a machine.

    no system fonts required
    Integrations

    Fits into your video stack.

    The built-in renderer is one of four ways out. The same story renders identically in HyperFrames and Remotion, or becomes a brief that any agent video skill can film in its own style.

    MP4 and GIF

    Headless Chrome and FFmpeg. H.264 with AAC at 30 fps, plus an eight-second GIF sized for a README.

    -e mp4

    HyperFrames

    A project driven by the hf-seek protocol. Passes hyperframes check and opens in the Studio for editing.

    -e hyperframes

    Remotion

    A React project where useCurrentFrame drives the engine. Swap in your own components while keeping the story.

    -e remotion

    Agent skills

    BRIEF.md carries the scenes, verbatim code, evidence and style suggestions for lemo-opuscar, OpenMontage or any video skill.

    -e brief
    Quick start

    Two commands to your first film.

    Requires Python 3.11 or newer, FFmpeg and Chrome or Chromium. The voice model, about 120 MB, downloads from GitHub Releases on the first voiced render.

    Install and render

    # install
$ pip install git+https://github.com/burhan-mujahid/repo2video
$ python -m playwright install chromium

# all five formats for a GitHub repository
$ repo2video rtk-ai/rtk -m all

# one format for the current folder, every export
$ repo2video . -m engineering -e all

# edit the script, then render it again
$ repo2video . -m marketing --plan-only -o film
$ repo2video --story film/story.json

    Claude Code plugin

    $ claude plugin marketplace add burhan-mujahid/repo2video
$ claude plugin install repo2video@repo2video

    Command-line reference

    targetFolder, GitHub URL or owner/repo. Defaults to the current folder.
    -m, --modemarketing, engineering, onboarding, release, social or all.
    -e, --exportComma-separated: mp4, hyperframes, remotion, brief, or all.
    -o, --outOutput folder. Defaults to repo2video-out/<name>-<mode>.
    --storyRender an edited story.json instead of analyzing the repository.
    --plan-onlyWrite facts.json and story.json without rendering.
    --voiceOverride the mode's Kokoro voice, for example bf_emma.
    --no-voiceCaptions, music and effects without narration.
